# Roadmap

## 0.1 Foundation
- Minimal net6.0 plugin project
- 300-action hard limit
- Event JSON schema
- Catalog-aware event validation
- Single session controller
- Optional structured AI plan validation
- Six event templates

## 0.2 Native bridge
- World-ready detection
- Player lookup
- Notifications and announcements
- Teleport, PvP, buff, and spawn adapters
- Main-thread execution

## 0.3 Player lifecycle
- Baseline snapshot
- Event tracking
- Final restoration
- Disconnect and elimination cleanup

## 1.0 Public release
- Dedicated-server regression testing
- Curated verified action catalog
- Installation package
- Thunderstore release preparation
