# AI-Assisted Development

BlueLuck Event was designed and generated through an AI-assisted development workflow.

The project began from explicit live-server requirements: a small V Rising event plugin, a strict 300-action ceiling, ready-to-use event definitions, safe customization, and a clear separation from the larger BattleLuck development project.

The AI produced the initial architecture, source files, schemas, validation rules, event templates, documentation, and release structure.

Human responsibilities remain essential:

- Defining product goals
- Supplying live-server requirements
- Reviewing generated code
- Building against current V Rising references
- Testing on a dedicated server
- Approving releases
- Reporting failures and requesting changes

The accurate marketing statement is:

> BlueLuck Event is an AI-generated implementation directed by live-server requirements and validated by humans.

No BattleLuck source files or Git history are included in this clean-room foundation.
